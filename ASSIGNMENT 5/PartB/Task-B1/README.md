# B1 – File Store and Buffering
Run in VS Code terminal:
```bash
javac PassStore.java
java PassStore
javac PassStore.java LineCounterBenchmark.java
java LineCounterBenchmark
```
It tests add/find/list, a missing ID and a damaged line; then measures 1 MB, 10 MB and 50 MB line counting and searches in files up to 100,000 records. Timings are machine-dependent.
